# 旅行記憶王 V1.0

全班即時連線的旅行主題記憶遊戲。原創文字與 emoji 題庫，7 類 × 7 件物品，共 49 件。適合投影、平板與手機使用。

## 快速啟動

1. 安裝 Node.js 20 或更新版本。
2. 在專案資料夾執行 `npm install`。
3. 執行 `npm start`。
4. 老師開啟 `http://localhost:3000`，建立房間。
5. 同一網路的學生可以開啟 `http://老師電腦區網IP:3000`，或部署到公開網址後掃 QR Code 加入。

## Render 雲端部署（建議）

1. 將解壓縮後的全部檔案上傳至自己的 GitHub repository（保留 `server.js`、`package.json`、`public/index.html`）。
2. 登入 https://render.com ，建立 **New > Web Service**，連結 GitHub repository。
3. Runtime 選 Node；Build Command 輸入 `npm install`；Start Command 輸入 `npm start`。
4. 選擇適合的方案與區域，按 Deploy，等待狀態顯示 Live。
5. 以 Render 提供的 `https://...onrender.com` 網址開啟教師端；學生用 QR Code 加入。
6. 如有設定自訂網域或反向代理，可將 `PUBLIC_URL` 環境變數設成公開 HTTPS 網址，以確保 QR Code 指向正確位置。

注意：某些免費雲端方案會休眠，首次開啟可能需要等待。請上課前先開啟並測試。Render 價格與限制以其官網最新公告為準。

## 課堂操作

- 教師選擇回合數（1–40）、答題秒數（5–90）、小組數（1–10）、四種模式輪流或指定模式。
- 學生掃 QR Code，輸入唯一的座號或姓名，系統依加入順序輪流分組。
- 教師按「開始遊戲」後顯示物品；確認全班看完，再按「隱藏物品，開始作答」。
- 每題有四個選項；每人只能送出一次。答對加 100 分。
- 全部學生送出後會提前揭曉，否則時間到揭曉。教師按「下一回合」。
- 顯示個人與小組排行榜，教師可匯出 CSV（可用 Excel 開啟）。

## 四種模式

1. **物品記憶**：記住 7 件物品，回答指定主題的物品。
2. **神祕物品**：觀看物品圖示，選出正確名稱。
3. **消失物品**：記住 7 件物品，隱藏後選出指定消失物品。
4. **位置記憶**：記住 7 件物品的順序，回答指定物品原本位置。

## V1 已知限制

- 房間、題目、成績暫存在伺服器記憶體，伺服器重啟或重新部署會遺失；房間最長保存約 12 小時。
- 教師憑證與學生重連憑證保存在該瀏覽器分頁的 sessionStorage；關閉分頁可能無法恢復。
- 不包含使用者帳號、永久成績庫、跨伺服器同步、教師上傳圖片或人工編輯題庫。
- 房間代碼不是密碼，請勿用於敏感資料；建議學生使用座號或暱稱，不輸入個人隱私資訊。
- 小組由加入順序自動分配，第一版不支援手動調整。
- 題庫使用 emoji，外觀可能因設備而異；未使用原桌遊受著作權保護的卡牌圖像。
- 適合單一 Node 伺服器實例，不應設定多實例負載平衡。

## 技術

Express + Socket.IO + qrcode；遊戲狀態及計分由伺服器控制，避免學生自行修改分數。
